# ADR 0013: Reproduce the Original's Presentation

- **Status:** Accepted (2026-10-06 to 2026-10-18; commits `509c667`, `9b9c9d3`, `05c11ab`,
  `ee705c3`, `f6ae356`).
- **Scope since 2026-10-19:** Classic presentation. The renderer is the game's own Compose
  Canvas renderer ([ADR 0019](0019-plain-kotlin-no-kubriko.md)); Extended may scale and widen the view
  ([ADR 0023](0023-classic-and-extended-rulesets.md)).

## Context

The original draws into a 640×480 VGA screen (each player's map window is `640/players - 1` by 480
or the map size if smaller, centred by `compute_window_size()`), with the 40×40 `PANEL.BMP` tiled
around it. Menus, prompts, lists and text pages use 320×200 mode 13h with the 8×16 `SETUP_FONT` and a
5×5 font. Much of its look comes from palette tricks: colour cycling for water, conveyors,
teleporters, glow and lava; a night palette (`NIGHT.PAL` via `NIGHT.LNK`) with light cones from
`LIGHT.DAT`; gamma correction of the palette; a white flash for A-bombs; fades; and a grey view for
the player who lost.

A modern UI with scalable layout and generic fonts was the earlier plan. It did not look like Tank
Arena when compared side by side with the original.

## Decision

- **Same screen geometry.** The game draws a 640×480 virtual screen scaled by whole numbers; map
  windows are placed like `compute_window_size()` / `write_screen()` (`legacyMapWindows` in
  `RenderSceneSupport.kt`). Menus and text pages are drawn as a 320×200 mode 13h screen shown 4:3.
- **Original pictures and fonts**, extracted from `DATA/` by `tools-mapconv` (`extract-pictures-png`,
  `extract-fonts`); the status display uses the original bitmaps (meters, icons, faces, banners).
- **Palette effects as Skia runtime shaders** instead of a palette: a 64³ colour lookup table
  (`night_lut.png`, generated by `extract-night`) for night maps and the night status display,
  palette-index cycling (entries 144–170) by day, a gamma table filter, fades, greyscale and the
  A-bomb flash as Compose modifiers.
- **Same flow and timing**: intro FLIs (`LOGO.FLI`, `TITLE.FLI`, decoded by `FliAnimation`) and
  credits, fades of 0.6 s in game and 0.3 s for text pages, success/failure text after a mission and
  back to the mode menu.

## Consequences

- The rewrite looks like the original when compared frame by frame (colour differences in DOSBox
  footage come from its scanline filter, not the game).
- Resolution independence is limited to integer scaling of the 640×480 screen; a different layout
  would be a new decision.
- The night look depends on Skia runtime effects; a web target must support them.
- On Android the shaders become AGSL runtime shaders (Android 13 and later)
  ([ADR 0025](0025-multiplatform-modules-and-android.md)).
